## Import rules

1. Sign in with an authorized teacher account and open the existing Teacher Content Library import workflow.
2. Select curriculum `TH-BASIC-CORE-2008-2017` and subject `THAI-LANGUAGE`.
3. Import one pack at a time and inspect every objective-code/grade match in the preview.
4. Preserve each objective's OBEC 2021 `must_know` / `should_know` classification.
5. Keep all imported lesson and assessment records as unpublished drafts until a Thai Language teacher reviews wording, age suitability and expected evidence.
6. The M4–M6 pack contains 36 shared objectives with three grade alignments each. Keep each shared objective as one objective; do not create three duplicate curriculum objectives. Confirm the importer preview preserves the shared grade scope before committing the import.

## Assessment design

The 957 tasks are formative prompts with expected evidence, not answer-keyed multiple-choice items. Reading, writing, listening, speaking and literature tasks should be assessed through observable learner work. Teachers should adapt source texts, vocabulary, task length and rubrics to the learners' grade and ability.

## Import boundary

These Markdown packs are not database content records. Do not create a system teacher, school, class or student to host them. Use the authenticated teacher workflow and existing organization permissions. The curriculum objectives and alignments are already seeded; importing packs should create only authorized draft content and assessment records.
