# Computer Studies M1–M3 — Complete Teacher Pack Import

**Curriculum:** Cambridge Click Start International Edition  
**Subject code:** COMPUTER-STUDIES  
**Curriculum code:** CLICK-START-M1-M3  
**Coverage:** M1 Learner's Book 4 (8 lessons), M2 Learner's Book 5 (9 lessons), M3 Learner's Book 6 (12 lessons). Total: 29 lessons and 87 original practice questions.

This combined file is designed for one import through the existing Teacher Content Import page. The objective codes assign each lesson to its exact grade automatically: M1-xx, M2-xx or M3-xx. Select the CLICK-START-M1-M3 curriculum and COMPUTER-STUDIES subject. The grade selector is only a fallback for packs without objective codes.

The lesson starters and questions are original classroom materials based on the published chapter titles, not copied textbook exercises. Consult the relevant learner's book for its exact subtopics, worked examples, screenshots and exercise sequence. Sample-paper chapters are assessment resources, not teaching lessons.

## Teacher guidance

Use school-approved software versions and explain interface differences where legacy versions are unavailable. Use fictional data in demonstrations. Do not require learners to publish personal information, create personal email accounts, share passwords or use real student contact details. MSWLogo, Scratch, QB64 and Flash may require installed or alternative tools; the current in-platform coding workspace runs JavaScript only. Students may submit code, screenshots and practical evidence for teacher review.

## Lesson starters

## M1 — Cambridge Learner's Book 4

## Lesson 1 — Know Your Computer

**Objective:** `M1-01` — Demonstrate the knowledge and practical skills for Know Your Computer.
**Book chapter:** 1  
**Learning outcomes:** Identify input and output devices, describe the CPU and memory, and explain computer uses and limitations.  
**Practical activity:** Learners classify classroom devices as input, output or processing/storage components and draw a simple computer-system diagram.  
**Practice**
1. Give two examples of input devices. **Answer:** Keyboard and mouse.
2. What is the CPU's main role? **Answer:** It processes instructions and data.
3. Give one limitation of computers. **Answer:** They do not independently understand context or make reliable judgements without suitable instructions and data.

## Lesson 2 — Using Windows

**Objective:** `M1-02` — Demonstrate the knowledge and practical skills for Using Windows.
**Book chapter:** 2  
**Learning outcomes:** Use the desktop, change desktop background and screen saver, set date/time, use File Explorer and open Accessories.  
**Practical activity:** Create a named class folder, make two subfolders, save a file and locate it again using File Explorer. Demonstrate display-personalisation settings where permitted.  
**Practice**
1. What is the desktop? **Answer:** The main screen/workspace shown after signing in.
2. Which tool helps you browse files and folders? **Answer:** File Explorer (Windows Explorer in the book).
3. Why use meaningful folder and file names? **Answer:** They make work easier to identify and retrieve.

## Lesson 3 — MS Word 2010: Formatting Text

**Objective:** `M1-03` — Demonstrate the knowledge and practical skills for MS Word 2010: Formatting Text.
**Book chapter:** 3  
**Learning outcomes:** Format fonts, highlight text, apply borders and shading, and align paragraphs.  
**Practical activity:** Type a short school notice and format its title, headings and body using font choices, highlighting, borders and alignment.  
**Practice**
1. What does font formatting change? **Answer:** The appearance of characters, such as typeface, size and style.
2. When is text highlighting useful? **Answer:** To draw attention to important words or phrases.
3. Name two paragraph alignment options. **Answer:** Left, centre, right or justified.

## Lesson 4 — Fun with Tux Paint

**Objective:** `M1-04` — Demonstrate the knowledge and practical skills for Fun with Tux Paint.
**Book chapter:** 4  
**Learning outcomes:** Use the Stamp tool, open a new drawing canvas, view pictures as a slide show and print a picture.  
**Practical activity:** Create a themed picture using stamps, save it, reopen it and present it to the class. Print only where teacher-approved.  
**Practice**
1. What is the Stamp tool used for? **Answer:** Adding ready-made pictures or objects to a drawing.
2. Why save a drawing? **Answer:** So it can be reopened or edited later.
3. What does a slide show do? **Answer:** Displays pictures one after another.

## Lesson 5 — MSWLogo: Drawing Polygons and Circles

**Objective:** `M1-05` — Demonstrate the knowledge and practical skills for MSWLogo: Drawing Polygons and Circles.
**Book chapter:** 5  
**Learning outcomes:** Use movement and pen-state commands, REPEAT, and commands for drawing polygons, circles and arcs.  
**Practical activity:** Learners write and run simple MSWLogo commands to draw a square, triangle and circle; save the resulting picture.  
**Practice**
1. What does PENUP do? **Answer:** Moves the turtle without drawing.
2. What does PENDOWN do? **Answer:** Allows the turtle to draw as it moves.
3. Why is REPEAT useful? **Answer:** It repeats a group of commands and reduces repeated typing.

## Lesson 6 — MSWLogo: Using PenColors and PenSizes

**Objective:** `M1-06` — Demonstrate the knowledge and practical skills for MSWLogo: Using PenColors and PenSizes.
**Book chapter:** 6  
**Learning outcomes:** Change pen colour and size and use these settings to improve a Logo drawing.  
**Practical activity:** Produce a labelled geometric picture using at least two pen colours and two pen sizes.  
**Practice**
1. Which command changes pen colour? **Answer:** SETPENCOLOR.
2. Which command changes pen thickness? **Answer:** SETPENSIZE.
3. Why check the pen settings before drawing? **Answer:** To ensure lines have the intended colour and thickness.

## Lesson 7 — MSWLogo: Text Commands and Arithmetic Operations

**Objective:** `M1-07` — Demonstrate the knowledge and practical skills for MSWLogo: Text Commands and Arithmetic Operations.
**Book chapter:** 7  
**Learning outcomes:** Use MAKE, SHOW, PRINT, LABEL and TYPE, and perform arithmetic operations in MSWLogo.  
**Practical activity:** Create named variables, display values and calculate simple sums, differences, products and quotients.  
**Practice**
1. What is a variable? **Answer:** A named place used to store a value.
2. What is the purpose of PRINT or SHOW? **Answer:** To display information or a result in the command area.
3. What is the result of 12 / 3? **Answer:** 4.

## Lesson 8 — Introduction to MS PowerPoint 2010

**Objective:** `M1-08` — Demonstrate the knowledge and practical skills for Introduction to MS PowerPoint 2010.
**Book chapter:** 8  
**Learning outcomes:** Identify the PowerPoint window, create, save, open and print a presentation, use views and run a slide show.  
**Practical activity:** Create a three-slide presentation introducing a school club; save it, switch views and run the slide show.  
**Practice**
1. What is a presentation? **Answer:** A set of slides used to communicate information.
2. Why save a presentation regularly? **Answer:** To prevent loss of work and preserve changes.
3. Which view is used to show slides to an audience? **Answer:** Slide Show view.


## M2 — Cambridge Learner's Book 5

## Lesson 1 — Know Your Computer

**Objective:** `M2-01` — Demonstrate the knowledge and practical skills for Know Your Computer.
**Book chapter:** 1  
**Learning outcomes:** Review computer components, input/output, processing, memory, uses and limitations.  
**Practical activity:** Learners map a familiar task (typing and printing a document) to input, processing, storage and output.  
**Practice**
1. Give one input and one output device. **Answer:** Keyboard and monitor (or printer).
2. What is the difference between hardware and software? **Answer:** Hardware is the physical equipment; software is the programs and instructions.
3. Why does a computer need memory? **Answer:** To hold data and instructions while work is being processed.

## Lesson 2 — Using Windows

**Objective:** `M2-02` — Demonstrate the knowledge and practical skills for Using Windows.
**Book chapter:** 2  
**Learning outcomes:** Manage the Windows desktop, files, folders and common system tools.  
**Practical activity:** Create a subject folder structure, copy and rename a file, and locate a saved document.  
**Practice**
1. What is a folder used for? **Answer:** Organising files and other folders.
2. What is the difference between copying and moving a file? **Answer:** Copying makes another copy; moving changes its location.
3. Why should files be backed up? **Answer:** To recover work if the original is lost or damaged.

## Lesson 3 — MS Office at a Glance

**Objective:** `M2-03` — Demonstrate the knowledge and practical skills for MS Office at a Glance.
**Book chapter:** 3  
**Learning outcomes:** Recognise common Office applications and choose an appropriate application for a task.  
**Practical activity:** Match classroom tasks to Word, PowerPoint or Excel and explain each choice.  
**Practice**
1. Which application is mainly used for documents? **Answer:** MS Word.
2. Which application is mainly used for slide presentations? **Answer:** MS PowerPoint.
3. Which application organises data in worksheets and cells? **Answer:** MS Excel.

## Lesson 4 — MS Word 2010: Inserting Objects and Drawing

**Objective:** `M2-04` — Demonstrate the knowledge and practical skills for MS Word 2010: Inserting Objects and Drawing.
**Book chapter:** 4  
**Learning outcomes:** Insert suitable objects and use drawing tools to create a clear document.  
**Practical activity:** Produce a one-page event flyer with a title, paragraph, picture or shape and a simple labelled diagram.  
**Practice**
1. Why insert a picture into a document? **Answer:** To illustrate or support the information.
2. What is a shape object? **Answer:** A drawing element such as a line, arrow, rectangle or circle.
3. What should you check when placing an object? **Answer:** Its size, position, text wrapping and relevance.

## Lesson 5 — MS PowerPoint 2010: Editing and Formatting Slides

**Objective:** `M2-05` — Demonstrate the knowledge and practical skills for MS PowerPoint 2010: Editing and Formatting Slides.
**Book chapter:** 5  
**Learning outcomes:** Edit slide content and format text and slide elements consistently.  
**Practical activity:** Create a four-slide presentation with a title slide, clear headings, readable text and relevant visuals.  
**Practice**
1. What is a slide layout? **Answer:** A predefined arrangement of placeholders on a slide.
2. Why use consistent formatting? **Answer:** It makes a presentation easier to follow.
3. What is one feature of an effective slide? **Answer:** Short readable text with relevant supporting visuals.

## Lesson 6 — Introduction to MS Excel 2010

**Objective:** `M2-06` — Demonstrate the knowledge and practical skills for Introduction to MS Excel 2010.
**Book chapter:** 6  
**Learning outcomes:** Identify workbooks, worksheets, rows, columns and cells; enter and edit simple data.  
**Practical activity:** Create a class stationery table with item, quantity and price columns; format headings and save the workbook.  
**Practice**
1. What is a cell? **Answer:** The box formed where a row and column meet.
2. What is a worksheet? **Answer:** A spreadsheet page made of rows and columns.
3. How is a cell identified? **Answer:** By its column letter and row number, such as A1.

## Lesson 7 — The Internet

**Objective:** `M2-07` — Demonstrate the knowledge and practical skills for The Internet.
**Book chapter:** 7  
**Learning outcomes:** Explain basic internet use, navigate websites and apply safe, responsible browsing habits.  
**Practical activity:** Compare two teacher-selected websites on the same topic and record author, date, evidence and purpose.  
**Practice**
1. What is a web browser? **Answer:** Software used to access websites.
2. What is a URL? **Answer:** The address of a resource on the web.
3. Give one way to assess a website's reliability. **Answer:** Check its author, evidence, date and agreement with other trustworthy sources.

## Lesson 8 — Learning Algorithms

**Objective:** `M2-08` — Demonstrate the knowledge and practical skills for Learning Algorithms.
**Book chapter:** 8  
**Learning outcomes:** Describe an algorithm and represent the steps of an everyday task in a clear sequence or flowchart.  
**Practical activity:** Draw a flowchart for borrowing a library book, including a decision such as whether the book is available.  
**Practice**
1. What is an algorithm? **Answer:** A clear, ordered set of steps for completing a task or solving a problem.
2. What does a decision symbol represent in a flowchart? **Answer:** A question or condition with possible branches.
3. Why should an algorithm be tested? **Answer:** To find missing, incorrect or unclear steps.

## Lesson 9 — Introduction to Scratch

**Objective:** `M2-09` — Demonstrate the knowledge and practical skills for Introduction to Scratch.
**Book chapter:** 9  
**Learning outcomes:** Recognise the Scratch interface, sprites, stage and blocks, and create a simple block-based program.  
**Practical activity:** Create a sprite that moves, speaks and responds to a start event. Save the project.  
**Practice**
1. What is a sprite? **Answer:** A character or object controlled in a Scratch project.
2. What is a script? **Answer:** A sequence of blocks that tells a sprite or project what to do.
3. What does an event block do? **Answer:** Starts a script when an event occurs, such as clicking the green flag.


## M3 — Cambridge Learner's Book 6

## Lesson 1 — Know Your Computer

**Objective:** `M3-01` — Demonstrate the knowledge and practical skills for Know Your Computer.
**Book chapter:** 1  
**Learning outcomes:** Consolidate understanding of computer components, processing, memory, storage, uses and limitations.  
**Practical activity:** Trace a data task from input to processing, storage and output; explain how hardware and software work together.  
**Practice**
1. What is the role of the CPU? **Answer:** It executes instructions and processes data.
2. How is RAM different from secondary storage? **Answer:** RAM is temporary working memory; secondary storage retains data without power.
3. Why are backups important? **Answer:** They help restore data after loss, corruption or device failure.

## Lesson 2 — Operating System

**Objective:** `M3-02` — Demonstrate the knowledge and practical skills for Operating System.
**Book chapter:** 2  
**Learning outcomes:** Explain the purpose of an operating system and identify its role in managing files, applications and hardware.  
**Practical activity:** Identify operating-system functions while opening applications, managing windows and organising files.  
**Practice**
1. What is an operating system? **Answer:** System software that manages computer hardware and provides services for applications.
2. Give one example of an operating system. **Answer:** Windows, macOS or Linux.
3. Why are operating-system updates important? **Answer:** They can improve security, stability and compatibility.

## Lesson 3 — MS Word 2010: Advanced Features

**Objective:** `M3-03` — Demonstrate the knowledge and practical skills for MS Word 2010: Advanced Features.
**Book chapter:** 3  
**Learning outcomes:** Apply advanced document features available in the installed Word version to produce a structured document.  
**Practical activity:** Prepare a multi-section report with consistent styles, page layout and appropriate document elements supported by the installed version.  
**Practice**
1. Why use styles in a long document? **Answer:** They keep headings and formatting consistent and support navigation.
2. What is the purpose of page layout settings? **Answer:** To control page size, margins, orientation and arrangement.
3. Why proofread before sharing a document? **Answer:** To correct errors and improve clarity and presentation.

## Lesson 4 — MS Word 2010: Mail Merge

**Objective:** `M3-04` — Demonstrate the knowledge and practical skills for MS Word 2010: Mail Merge.
**Book chapter:** 4  
**Learning outcomes:** Explain the purpose of mail merge and combine a main document with a data source to produce personalised documents.  
**Practical activity:** Use a teacher-provided fictional contact list to create personalised invitation letters; do not use real student addresses.  
**Practice**
1. What is mail merge? **Answer:** A feature that combines a main document with a data source to create personalised copies.
2. What is a data source? **Answer:** The table or list containing variable information such as names.
3. Why preview merged documents? **Answer:** To check that fields and records appear correctly before completing the merge.

## Lesson 5 — MS PowerPoint 2010: Advanced Features

**Objective:** `M3-05` — Demonstrate the knowledge and practical skills for MS PowerPoint 2010: Advanced Features.
**Book chapter:** 5  
**Learning outcomes:** Use advanced presentation features available in the installed version to create a coherent presentation.  
**Practical activity:** Build a short topic presentation using suitable transitions, animations and media without distracting from the message.  
**Practice**
1. What is the difference between a transition and an animation? **Answer:** A transition affects how a slide changes; an animation affects an object on a slide.
2. Why should animation be used carefully? **Answer:** Too much movement distracts the audience.
3. What should be checked before presenting on another computer? **Answer:** Fonts, media, layout, playback and file compatibility.

## Lesson 6 — More About MS Excel 2010

**Objective:** `M3-06` — Demonstrate the knowledge and practical skills for More About MS Excel 2010.
**Book chapter:** 6  
**Learning outcomes:** Extend spreadsheet skills using formulas, functions, cell references and suitable data presentation.

**Practice**
1. What does a formula usually begin with in Excel? **Answer:** An equals sign (=).
2. What does SUM do? **Answer:** Adds the values in selected cells.
3. Why use a chart? **Answer:** To communicate patterns or comparisons in data.

**Book chapter:** 7  
**Learning outcomes:** Extend Scratch projects using events, control, sensing, variables and multiple sprites as supported by the editor.  
**Practical activity:** Create a short interactive quiz or game with a score variable, user input and a clear end condition.

2. What does a loop do? **Answer:** Repeats a set of instructions.

## Lesson 8 — Introduction to QB64

**Objective:** `M3-08` — Demonstrate the knowledge and practical skills for Introduction to QB64.
**Book chapter:** 8  
**Learning outcomes:** Explain what QB64 is and create, run and save a simple program in an approved QB64 environment.  
**Practical activity:** Write a small program that displays a welcome message and explain how the program is run.  
**Practice**
1. What is QB64? **Answer:** A BASIC programming environment compatible with the QBasic language family.
2. What is source code? **Answer:** Human-readable instructions written in a programming language.

## Lesson 9 — QB64: Statements

**Objective:** `M3-09` — Demonstrate the knowledge and practical skills for QB64: Statements.
**Book chapter:** 9  
**Learning outcomes:** Recognise and use introductory QB64 statements as taught in the textbook.  
**Practical activity:** Recreate a short textbook-style program in the approved environment and annotate what each statement does.  
**Practice**
1. What is a programming statement? **Answer:** An instruction written in a programming language.
2. Why does statement order matter? **Answer:** The computer follows instructions in sequence unless control statements change the flow.
3. What is a syntax error? **Answer:** An error caused by code that does not follow the language's rules.

## Lesson 10 — QB64: Programming Statements

**Objective:** `M3-10` — Demonstrate the knowledge and practical skills for QB64: Programming Statements.
**Book chapter:** 10  
**Learning outcomes:** Apply the programming statements covered in the chapter to control a simple program.  
**Practical activity:** Build a small menu-driven or calculation program using only statements introduced in the learner's book; test normal and boundary inputs.  
**Practice**
1. What is selection in programming? **Answer:** Choosing which instructions to run based on a condition.
2. What is iteration? **Answer:** Repeating instructions.
3. Why test boundary values? **Answer:** To check behaviour at the limits of the expected input range.

## Lesson 11 — Introduction to Macromedia Flash

**Objective:** `M3-11` — Demonstrate the knowledge and practical skills for Introduction to Macromedia Flash.
**Book chapter:** 11  
**Learning outcomes:** Understand the purpose of Flash as a multimedia/animation authoring tool and identify basic animation concepts in the book.  
**Practical activity:** Analyse a simple teacher-provided animation and storyboard its frames or motion. If Flash is unavailable, use an approved animation tool and label it as an alternative.  
**Practice**
1. What is an animation? **Answer:** A sequence of images or states that creates the appearance of movement.
2. What is a frame in an animation timeline? **Answer:** One individual step or image in the sequence.
3. Why is Macromedia Flash considered legacy software? **Answer:** Flash Player has been discontinued; old files may require safe, offline or alternative viewing methods.

## Lesson 12 — Introduction to Email

**Objective:** `M3-12` — Demonstrate the knowledge and practical skills for Introduction to Email.
**Book chapter:** 12  
**Learning outcomes:** Explain email, identify message fields and practise safe, appropriate email communication.  
**Practical activity:** Draft (do not send) a formal email using a fictional recipient; identify subject, greeting, message and sign-off, and inspect a sample suspicious message.  
**Practice**
1. What is the subject field used for? **Answer:** A short description of the email's purpose.
2. What is an attachment? **Answer:** A file sent with an email.
3. Give one warning sign of a phishing email. **Answer:** Unexpected urgency, suspicious links, requests for passwords or an unfamiliar sender.
